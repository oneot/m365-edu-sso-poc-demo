학교별 Microsoft 365 SSO PoC 시연 영상

학교마다 따로 있는 Microsoft 365 테넌트를 그대로 두고, SAML 2.0 IdP(SEN 역할) 하나에 도메인 페더레이션으로 연결한 PoC입니다. 로그인 성공·거부·통합 아이디 라우팅·위험 로그인 탐지와 차단을 헤드리스 Chromium으로 녹화했습니다.

  • 환경 테스트 도메인 joowon.me · 학교 A(Microsoft 365 E5 데모 테넌트) · 학교 B(Microsoft 365 A5 데모 테넌트)
  • IdP auth.joowon.me(테스트 IdP) · 로그인 화면 login.joowon.me
  • 결과 표시 각 영상 끝 화면과 아래 '실제 결과'는 받은 토큰(계정·테넌트)과 Microsoft 응답(오류 코드)에서 읽은 값입니다
  • 문서 설계·시험 결과(README) · 이 사이트 저장소
테스트 전용 계정·도메인입니다. 관리 포털 화면의 관리자 계정·테넌트 ID·접속 IP는 녹화 중 가렸습니다.
